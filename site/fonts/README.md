# Fonts

Subsets (woff2) of two typefaces under the SIL Open Font License 1.1, made with fonttools'
pyftsubset for the characters the website uses:

- `inter.woff2`: Inter (variable), `OFL-Inter.txt`.
- `dussek-serif.woff2`, `dussek-serif-italic.woff2`: Source Serif 4 (variable), renamed "Dussek
  Serif" as the license asks of a modified version (its Reserved Font Name), `OFL-SourceSerif4.md`.
